# 空翻成功判定

`Unitree-Go2-Backflip-V1.6` 在训练和播放环境中都启用分阶段评估。指标只读取仿真真实状态，不改变 actor/critic 观测、奖励权重或终止条件，也没有额外成功奖励。

## 判定过程

每个回合独立记录状态，顺序为起跳、完成后翻、稳定落地。阈值集中在 `src/tasks/go2/backflip/evaluation.py` 的 `BackflipEvaluationCfg` 中。

| 阶段 | 默认条件 |
| --- | --- |
| 起跳 | 已观察到脚部支撑；四脚同时离地至少 0.06 秒，机身比最后支撑时抬升至少 0.06 米 |
| 完成后翻 | 从首次离地开始积分负 Y 轴角速度；确认起跳后，累计净转角达到 360°±30°，且经过倒置姿态（机身重力 Z 分量大于 0.5） |
| 落地支撑 | 至少三脚接触地面，必然包含前腿和后腿；机身倾斜小于 20°，高度在 0.26–0.40 米之间 |
| 稳定保持 | 水平速度小于 0.5 m/s，垂直速度绝对值小于 0.3 m/s，角速度模长小于 1 rad/s；满足支撑、姿态、转角条件连续至少 0.2 秒 |
| 碰撞约束 | 从首次离地尝试开始，机身、大腿或小腿发生非脚部接触即判本回合失败，之后恢复站立也不能重新计为成功 |

接触判定使用当前接触力，阈值为 1 N；不使用接触历史来判断当前是否腾空。指标与奖励一样在每个控制步采样，因此不能保证捕获两个控制采样之间的极短碰撞。

“完成后翻”是本回合曾达到该阶段的标记；“最终成功”不是永久锁定标记。短暂稳定后再次失稳会撤销成功，需要重新满足连续稳定时长；发生非脚部碰撞则永久失败。回合结束时的结果才计入成功率，站着不动、普通跳跃、前翻、仅旋转而未倒置、翻转后摔倒均不能成功。

## 训练日志

TensorBoard 记录以下三个指标，范围为 0–1，乘以 100 即百分比：

- `Episode_Metrics/backflip_takeoff_rate`：完成起跳的回合比例。
- `Episode_Metrics/backflip_full_flip_rate`：完成规定后翻的回合比例，后续落地失败不撤销已完成翻转的记录。
- `Episode_Metrics/backflip_success_rate`：最终稳定落地的回合比例。

三者分母均包含失败回合，成功率不是“已起跳回合中的成功率”。mjlab 默认按步数平均指标，此处仅在终止步输出结果，并按本回合实际观察步数补偿，确保最终得到回合结果而非成功状态持续时间的比例。初始随机回合计时不会使指标超过 1；训练初始的部分回合仍可能因剩余时间不足而失败。

正式比较检查点时，应使用完整回合、相同随机种子与随机化设置，统计足够多回合，并人工检查部分录像。小样本测试仅验证接口，不代表整体成功率。

## 本次相关修正

- 姿态跟踪改为负 Y 轴后翻，与 `pitch_progress` 共用 0.5–1.15 秒翻转时间窗。
- 下蹲目标从 0.24 米提高到 0.28 米，随后恢复到 0.30 米。
- 支撑宽度改为 0.30 米，修正原先 `0.3 * zeros` 导致的零目标；起跳前保留脚相对机身滑移项，落地后使用世界坐标系滑移约束（见下文）。
- 新增后腿落地姿态奖励，空中收腿奖励在 1.0–1.15 秒与之平滑交接。

## 后腿落地奖励

| 项目 | 目标与时间 | 权重 |
| --- | --- | ---: |
| `feet_distance` | FL/FR/RL/RR 的机身坐标系 Y 目标为 +0.15/−0.15/+0.15/−0.15 米；保持 t<0.5 或 t>1.2 秒生效 | −1.0 |
| `air_tuck_pose` | 保留原收腿姿态；0.5–0.65 秒进入，保持至 1.0 秒，随后平滑淡出，1.15 秒归零 | −0.8 |
| `rear_leg_landing_pose` | 只约束 RR/RL，两腿分别恢复到髋 0、大腿 1.0、小腿 −1.5 rad；1.0–1.15 秒逐渐启用，之后保持至回合结束 | −1.0 |

交接系数为 `s = u²(3−2u)`，其中 `u = clamp((t−1.0)/0.15, 0, 1)`。收腿退出系数为 `1−s`，后腿落地启用系数为 `s`，交接两端斜率均为零。

后腿姿态原始误差为两条后腿的 `4×髋关节误差² + 大腿误差² + 小腿误差²` 之和，再乘交接系数与配置权重。髋关节误差占比更大，用于约束左右后腿外展。后腿关节显式按 RR hip/thigh/calf、RL hip/thigh/calf 解析，不依赖模型内部关节排序。

这些是后续训练的初始奖励设置，并不保证必然改善动作。actor 观测、成功判据、机身高度奖励和其余权重保持原设置；尚未引入成功奖励。

已有检查点可直接使用新增评估指标；姿态和下蹲奖励的改变需要重新训练才会影响策略动作。


## 前腿髋关节落地约束

新增 `front_hip_landing_pose`，训练和播放配置均注册此奖励。只按名称解析
`FR_hip_joint`、`FL_hip_joint`，目标角度均为 0 rad，不新增大腿、小腿约束。

原始误差为 `q_FR_hip² + q_FL_hip²`，乘配置权重 **−4.0** 和平滑系数 `s`。
`s` 复用上述 smoothstep：1.0 秒前为零，1.0–1.15 秒逐渐启用，1.15 秒后
保持为 1，持续至 2 秒回合结束。镜像外张同样受到惩罚，不会被左右对称项抵消。

前腿前伸奖励及其他奖励权重保留。该项不改变动作、观测或网络结构，已有检查点
可继续加载；需要重新训练或微调才能改变策略行为，直接播放旧检查点不会修正外张。
新增奖励本身不代表已经验证训练效果改善。


## 落地后抑制滑移和动作抖动

从 `LANDING_START = 1.15` 秒起至回合结束：

- `stance_foot_slip` 以权重 −0.15 惩罚当前触地脚在世界坐标系下的水平速度平方和。
  当前接触阈值为 1 N，不使用历史接触判断落地后的脚是否仍触地。
  空中脚不受此项惩罚；脚在地面静止时，机身移动不会被误计为脚端滑移。
- `action_rate` 的有效系数从 −0.001 提高为 **−0.005**。
  配置保留基础权重 −0.001，通过 `landing_scale=5.0` 实现分阶段系数。

1.15 秒前保留原动作平滑强度；滑移项仍只在起跳前 t<0.45 秒按原相对机身
速度和接触历史计算，0.45–1.15 秒不生效。训练和播放配置一致，网络与观测维度
不变。需要重新训练或微调，新增惩罚才会影响动作；未据此宣称动作质量已经改善。


## 显式 PD 控制的物理步长

空翻训练和播放均使用物理步长 **0.0025 秒**、`decimation=8`。
策略控制周期仍为 0.02 秒（50 Hz），显式 PD 扭矩和物理仿真更新为 400 Hz。
PD 增益保持 70/3，armature 保持原配置，不同时引入惯量调整。

原 0.005 秒步长下，固定站姿目标也会出现明显关节抖动；减小步长的静态对照
消除了这项抖动。已有策略可加载，但动力学离散化改变后，需要训练或微调再评估
完整空翻与落地效果；静态站姿稳定不等于完整任务已学会。
